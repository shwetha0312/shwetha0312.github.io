## 🚀 What is PLD+?

**PLD+ (Prompt Lookup Decoding Plus)** is a speculative decoding technique for accelerating inference in **input-guided tasks** like code editing, summarization, and multi-turn dialogue. It improves upon prior string-matching approaches (like PLD) by leveraging **model artifacts**—namely, **attention states** and **hidden states**—to identify optimal draft spans.

No draft model. No fine-tuning. Just faster decoding out-of-the-box.

## 🧠 How Does It Work?

During decoding step *t*, PLD+ retrieves spans from the input where the last token *xt* previously appeared. These candidate spans are **ranked** based on either the:

- Cosine similarity between hidden states
- Attention scores from “induction heads” known to match prefixes and perform copying

Once ranked, a draft sequence of *K* tokens is proposed from the best span and **verified** using the base model’s predictions. Matching tokens are accepted in bulk—saving compute and latency.

```python
# Simplified logic of PLD+ draft + verify
for t in range(T):
    P = find_positions(xt, input)
    j_star = rank_by_hidden_state_similarity(P)
    draft = input[j_star+1 : j_star+1+K]
    verified = model.generate_and_verify(draft)
    output.extend(verified)
```

## 🧪 When Does It Work Best?

PLD+ excels in **input-guided settings**, where the output reuses input spans:

- Code editing
- Text transformation (simplification, grammar fixes)
- Summarization
- Multi-turn dialogue (with clear context)

Not ideal for:
- Open-ended generation
- Tasks with low input-output overlap

## 🧭 PLD+ vs Other Methods

| Method | Needs Draft Model? | Finetuning? | Speedup |
|--------|---------------------|-------------|---------|
| PLD | ❌ | ❌ | Moderate |
| PLD+ | ❌ | ❌ | High |
| EAGLE | ✅ | ✅ | High |
| REST | ❌ | ❌ | Low (needs datastore) |

PLD+ is **plug-and-play** and supports newer models like Mistral and Llama-2 with zero modifications.


## 🧠 Takeaways

- PLD+ speeds up decoding in a tuning-free, model-agnostic manner for input-guided tasks.
- It beats both heuristic (PLD) and fine-tuned (EAGLE) baselines on most input-guided tasks.
- Its secret weapon? Using hidden states and attentions already computed during the generation process to select the best draft tokens conditioned on input context
